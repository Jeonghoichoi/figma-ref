# figref

`.fig` 파일과 호환되는 브라우저 기반 벡터 디자인 에디터 (개인 학습/상호운용성 프로젝트).

- 설계: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- 포맷 분석: [docs/fig-format.md](docs/fig-format.md)

```bash
pnpm install
pnpm dev                  # 뷰어 실행 → http://127.0.0.1:5173
pnpm test                 # 전체 테스트
pnpm typecheck
pnpm inspect <file.fig> --out fixtures/out/<name> --roundtrip
```

분석할 샘플은 `fixtures/` 에 넣는다 (`*.fig` 는 git에서 제외됨).

## 홈 화면 (파일 브라우저)

- **새로 만들기**: 빈 캔버스, 또는 아트보드 프리셋(Desktop, iPhone, iPad, Instagram, YouTube 썸네일, A4 등)으로 실제 `.fig` 파일을 만든다.
  `.fig` 스키마는 저장소에 넣지 않으므로, **한 번이라도 열어 본 `.fig` 파일의 스키마**를 브라우저에 기억해 두었다가 쓴다.
- **최근 파일**: 열었거나 만든 파일. 썸네일, 마지막 편집 시각, 크기를 보여준다. ⋯ 메뉴에서 열기, 이름 바꾸기, `.fig` 다운로드, 삭제를 할 수 있다.
- **샘플**: `fixtures/`의 `.fig` (파일에 들어 있는 썸네일로 표시). 열면 최근 파일에 복사본이 생기고, 편집 내용은 그 복사본에 저장된다.
- `.fig` 가져오기: 버튼을 누르거나 화면에 파일을 끌어다 놓는다.
- 파일은 이 브라우저의 IndexedDB에 저장된다. 편집하면 1.5초 뒤 자동 저장되고(⌘S로 즉시 저장), 홈으로 돌아갈 때 썸네일도 갱신된다.

주소: `#file=<id>` 라이브러리 파일 (새로고침해도 유지) · `?open=sample.fig` 샘플 바로 열기 · `&node=19:2` 해당 노드로 확대

## 에디터

| 도구 | 키 | | 편집 | 키 |
|---|---|---|---|---|
| 선택 | V | | 실행 취소 / 다시 실행 | ⌘Z / ⇧⌘Z |
| 손(이동) | H, Space+드래그 | | 복제 / 복사 / 붙여넣기 / 잘라내기 | ⌘D / ⌘C / ⌘V / ⌘X |
| 프레임 | F | | 그룹 / 그룹 해제 | ⌘G / ⇧⌘G |
| 사각형 | R | | 삭제 | ⌫ |
| 원 | O | | 앞으로 / 뒤로 · 맨 앞 / 맨 뒤 | ⌘] / ⌘[ · ⌥⌘] / ⌥⌘[ |
| 선 | L | | 조금씩 이동 | 방향키 (⇧ 10px) |
| 텍스트 | T | | 숨기기 / 잠그기 | ⇧⌘H / ⇧⌘L |

- 클릭: 프레임 안의 레이어를 선택 (그룹은 통째로) · 더블클릭: 그룹 안으로 들어가기 / 텍스트 편집 · ⌘클릭: 가장 안쪽 레이어
- 드래그: 이동 (다른 프레임 위에 놓으면 그 안으로 들어감, ⇧ 축 고정) · 핸들: 크기 조절 (⇧ 비율 유지)
- 빈 곳이나 프레임 안의 빈 곳에서 드래그: 범위 선택 · 프레임 자체는 이름표를 잡고 이동
- Enter: 자식 선택 · ⇧Enter: 부모 선택 · Esc: 부모로 / 선택 해제
- 레이어 패널: 드래그로 순서·부모 변경, 더블클릭으로 이름 바꾸기, 눈/자물쇠 버튼
- 속성 패널: 위치·크기·회전·모서리·불투명도·블렌드, 채우기/선/효과 추가·수정·삭제, 글자 크기·정렬
- 확대/축소: ⌘+스크롤, 핀치 · 전체 보기 ⇧1 · 100% ⇧0 · 선택 항목으로 ⇧2
- 상단 ◆: 홈으로 · 가운데 파일 이름: 클릭해서 이름 바꾸기 · **.fig 다운로드**: 현재 문서를 `.fig` 파일로 내보내기

브라우저 E2E 테스트 (`pnpm dev` 실행 중이고 `fixtures/sample333.fig`가 있을 때): `pnpm e2e` (홈 화면 14개 + 에디터 16개 항목)
